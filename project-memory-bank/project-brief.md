# Project Brief

## Purpose

AI Lexicon is an interactive web guide for engineers who want practical, copy-ready patterns for using AI in software development.

## Primary User

A developer or technical learner downloading the project for the first time and wanting to run, inspect, customize, or deploy the guide.

## Current Product

The product is a single-page React application with searchable and expandable guide content. It covers prompting, coding workflows, optimization, testing, architecture, tooling, and AI-first delivery practices.

## Success Criteria

- A first-time engineer can install dependencies and run the app locally.
- The app builds into a static production bundle.
- Project documentation explains setup, structure, dependencies, customization, troubleshooting, and deployment.
- Future maintainers can understand the current state from this memory bank.
